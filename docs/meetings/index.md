# Robot Motion Control 회의 기록

매주 회의 후 수동으로 갱신하는 회의 문서 목록이다. 각 문서는 저장된 회의록과 대화 기반 보충 내용을 분리하고, 마지막에 현재 결론을 종합한다.

| 회의일 | 주제 | 입력 회의록 | 상태 | 문서 |
|---|---|---|---|---|
| 2026-08-12 | Robot Motion Control 수정 방향 논의 | 원본 파일 미확인 | 확인 필요 | [`2026-08-12.md`](2026-08-12.md) |

## 상태 기준

- `정리 완료`: 회의록과 전달된 대화 내용이 종합됨
- `보충 대기`: 회의록은 있으나 대화 기반 보충 내용이 아직 없음
- `확인 필요`: 출처 간 충돌, 원본 부재 또는 결정되지 않은 범위가 있음

## 수동 갱신 방법

1. 회의 자료를 `Robot Motion Control Meeting/`에 저장하거나 경로를 지정한다.
2. 대화에서 회의일, 다음 회의일, 보충 설명과 정정 사항을 전달한다.
3. `이번 주 회의 문서 업데이트`라고 요청한다.
4. 갱신된 회의 문서와 [`../research-direction.md`](../research-direction.md)의 변경 내용을 확인한다.
